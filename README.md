# 脳トレメーカー

ボタンを押すだけで、あたらしい「脳トレ教材」(めいろ／なかまはずれさがし／まちがいさがし)が
自動でできあがる、印刷用のプログラムです。インターネットが無いパソコンでも使えます。

**インストールは不要です。** `web/脳トレメーカー.html` というファイル1つだけを
施設のパソコンにコピーして、ダブルクリックで開くだけで使えます(Chrome・Edgeなど、
普段お使いのブラウザで開きます)。

## 使い方(施設のパソコンで)

1. `web` フォルダの中の `脳トレメーカー.html` をダブルクリックして開きます。
   (ブラウザで開くだけなので、何もインストールする必要はありません)
2. 「むずかしさ」を選びます(やさしい／ふつう／むずかしい)。
3. ボタンを押します。
   - **全部まとめて1つ作る**：めいろ・なかまはずれさがし・まちがいさがしが1つにまとまります。
   - **めいろ／なかまはずれさがし／まちがいさがし**：1種類だけ作りたいときに押します。
4. 少し待つと、印刷プレビュー画面が自動で開きます。
5. そのまま「印刷」を押してください。

ボタンを押すたびに、**毎回ちがう新しい問題**が作られます。
「こたえのページも印刷する」にチェックを入れておくと、職員さん用の答え合わせページも一緒に印刷されます。

印刷プレビューが自動で開かない場合は、キーボードで `Ctrl+P`(Macは `⌘+P`)を押してください。

## 施設のパソコンへの持って行きかた

`web/脳トレメーカー.html` の1ファイルだけをUSBメモリ等でコピーすれば完了です。
Windows・Mac・Chromebookなど、ブラウザさえあればどのパソコンでも同じように動きます。
ネット接続は不要です(開いたあとは一切通信しません)。

## こまったときは

- 印刷の文字が小さすぎる／大きすぎる → 印刷プレビュー画面の「用紙に合わせる／倍率」設定で調整できます。
- 印刷イメージが崩れる → 印刷プレビューの「詳細設定」で「背景のグラフィック」をONにしてください。
- 何も起きない → ブラウザの設定でポップアップやJavaScriptがブロックされていないか確認してください
  (`脳トレメーカー.html` は他サイトと通信しない単独のファイルなので、基本的にブロックされません)。
